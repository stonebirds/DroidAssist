# DroidAssist 1.1.0

这是首个面向非开发用户提供完整安装资产的版本。

## 新增

- 正式签名的 Android Release APK。
- macOS Apple Silicon 一键服务包。
- macOS Intel 一键服务包。
- Windows x64 一键服务包。
- 便携包内置 Java 21、Ktor 服务和 cloudflared。
- 启动后自动展示公网地址、二维码、服务状态和手机操作步骤。
- Mac/Windows 启动、状态和停止脚本。
- 普通用户快速开始、Windows 技术部署和发布维护文档。
- 0BSD 开源协议，允许自由使用、修改、分发和商业使用。

## 已有远控能力

- WebSocket 实时连接通知和 WebRTC 信令。
- MediaProjection 整屏捕获。
- WebRTC P2P 实时画面。
- 点击、长按、滑动、返回、Home 和最近任务。
- 临时/永久授权、可信设备和最近匹配码。
- 独立远控页面和可收起控制面板。

## 使用提示

- 开发测试阶段的 `1.0.8` 使用调试签名，不能被本版本正式签名 APK 覆盖。请先卸载旧版再安装；卸载会清除旧版应用数据。
- 三个桌面服务包按 CPU 架构选择，不可混用。
- Quick Tunnel 完全停止后重新启动可能更换公网地址。
- Mac、Windows 和 Android 首次运行可能显示来源确认。
- 当前没有 TURN，部分受限网络可能无法建立 P2P。

## 停止服务

- 仅关闭浏览器页面不会停止电脑服务。
- Mac：回到服务包解压目录，双击 `3-Stop-DroidAssist.command`。
- Windows：回到服务包解压目录，双击 `3-Stop-DroidAssist.cmd`。
- 停止脚本不会删除数据库。再次启动后如果公网地址变化，需要在两台手机上更新服务器地址。

下载后可使用随 Release 提供的 SHA-256 文件校验完整性。
