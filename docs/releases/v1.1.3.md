# DroidAssist 1.1.3

本版本重点改善相册二维码识别、扫码界面、会话断开和被协助端前后台稳定性。

## 新增与修复

- 相册二维码改用离线 ML Kit 模型，改善小型、旋转、倾斜和复杂背景中的二维码识别。
- 一张图片中识别到多个二维码时显示候选列表，可选择需要的服务器地址。
- 扫码页移除方形边框，改为全屏柔光扫描动画，并提高关闭按钮清晰度。
- 协助端设备页和远控面板增加“断开协助”，确认后双方立即结束画面、控制和共享服务。
- 退出远控页面仍保持连接，重新打开时保留之前选择的画质。
- WebRTC 会话配置、信令处理和挂断移出 Compose 主线程，降低切回前台后界面卡住的概率。
- 默认自适应画质调整为 720p/20 fps，弱网和中端设备负载更稳；仍可手动选择 1080p/30 fps。

## 使用提示

- 从相册识别多个二维码时，服务器地址会优先显示；仍应确认内容属于自己的 DroidAssist 服务。
- “退出远控页面”只返回设备页；需要结束连接时使用“结束并断开协助”或设备页的“断开”。
- Android 系统保护的相机、支付、密码和锁屏页面仍可能在远端显示黑色，这属于系统安全限制。
- 两台手机都建议升级到本版本。

下载后可使用 Release 中的 SHA-256 文件校验完整性。
