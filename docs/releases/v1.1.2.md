# DroidAssist 1.1.2

本版本重点改善远程画面清晰度、远控操作面板和手机扫码体验。

## 新增与修复

- 远控返回、主页和任务按钮改为紧凑图标布局，窄屏不再换行。
- 画质默认使用网络自适应模式，捕获上限提升到短边 1080p、30 fps。
- 增加手动画质选择，支持 720p/1080p 和 10/15/20/30 fps。
- 画质参数通过 WebRTC DataChannel 实时下发，切换时不需要断开重连。
- 扫码页改为固定竖屏，增加关闭、手电筒和从相册识别二维码。
- 内置扫码预览改用 TextureView，改善屏幕共享期间打开扫码页后远端变黑的问题。
- 日志记录实际捕获尺寸、帧率、画质模式和画质切换结果。

## 使用提示

- 网络正常时保留默认“自适应”即可；画面卡顿时可改为 720p/15 或 20 fps。
- 扫码页右下角可以选择相册中的二维码图片，左下角可以开关手电筒。
- 第三方相机、支付、密码、锁屏或使用 `FLAG_SECURE` 的页面仍可能被 Android 系统强制显示为黑色。退出该页面后远端画面应自动恢复。
- 两台手机都应升级到本版本，画质控制消息才会生效。

下载后可使用 Release 中的 SHA-256 文件校验完整性。
