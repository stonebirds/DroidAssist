# DroidAssist 1.1.1

本版本重点改善首次部署和两台手机之间的信息录入体验。

## 新增与修复

- 修复部分网络无法加载电脑启动页二维码的问题，二维码现在完全在本机离线生成。
- Android 设置页增加扫码图标，可直接扫描电脑页面填写服务器地址。
- 临时授权和永久授权均可一键复制完整授权信息。
- 协助端可从剪贴板解析并同时填入匹配码和连接密码。
- 设置页右上角增加诊断日志，可查看、复制或清空，并自动保留最近记录。
- 修复手机 WebSocket 短暂重连时 offer/answer/ICE 信令直接丢失的问题。
- 修复设备重连后重复收到连接请求、导致授权弹窗重新出现的问题。
- 增加多个 STUN 入口和 ICE 失败自动重启，改善授权后无画面的情况。
- Mac 和 Windows 启动脚本可识别 Cloudflare Quick Tunnel HTTP 429，并自动分段重试三次。
- 限流持续存在时，明确提示本地服务状态、等待时间和换网方案。

## 使用提示

- 两台手机都需要安装本版本 APK，并连接同一个电脑页面显示的服务器地址。
- 被协助端生成授权后点击“复制完整授权信息”；协助端复制该文本后点击“从剪贴板填入授权”。
- Cloudflare 429 是匿名隧道的临时限制，不代表服务包损坏。自动重试仍失败时，请等待 10-20 分钟或切换电脑网络。
- 便携服务包必须完整解压后运行，不能直接在 ZIP 预览窗口中启动。

## 停止服务

- Mac：双击 `3-Stop-DroidAssist.command`。
- Windows：双击 `3-Stop-DroidAssist.cmd`。
- 仅关闭浏览器页面不会停止服务；停止脚本不会删除数据库。

下载后可使用 Release 中的 SHA-256 文件校验完整性。
