DroidAssist Mac 一键服务包
==========================

第一次使用：
1. 完整解压 ZIP 文件，不要直接在压缩包预览中运行。
2. 双击“1-Start-DroidAssist.command”。
3. 系统如有安全提示，请在“系统设置 -> 隐私与安全性”中选择仍要打开。
4. 等待浏览器自动打开服务页面。
5. 在两台 Android 手机上安装 DroidAssist APK，打开“设置”并扫描页面二维码。

日常使用：
- 启动：双击“1-Start-DroidAssist.command”。重复启动不会重复创建服务。
- 状态：双击“2-Status.command”。
- 停止：双击“3-Stop-DroidAssist.command”。

数据库和日志保存在：
~/Library/Application Support/DroidAssist

软件包已经内置 Java 和 cloudflared，不需要安装 Android Studio、JDK 或 Homebrew。
Quick Tunnel 完全停止后再次启动，公网地址可能变化；两台手机需要使用同一个新地址。
如果提示 Cloudflare HTTP 429，请让脚本完成自动重试；仍失败时等待 10-20 分钟或切换网络，不要连续反复启动。
