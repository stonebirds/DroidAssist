DroidAssist Windows 一键服务包
==============================

第一次使用：
1. 完整解压 ZIP 文件，不要直接在压缩包中运行。
2. 双击“1-Start-DroidAssist.cmd”。
3. Windows 如显示安全提示，请确认文件来自 DroidAssist GitHub Release 后选择继续运行。
4. 等待浏览器自动打开服务页面。
5. 在两台 Android 手机上安装 DroidAssist APK，并按页面提示填写服务器地址。

日常使用：
- 启动：双击“1-Start-DroidAssist.cmd”。重复启动不会重复创建服务。
- 状态：双击“2-Status.cmd”。
- 停止：双击“3-Stop-DroidAssist.cmd”。

数据库和日志保存在：
%LOCALAPPDATA%\DroidAssist

软件包已经内置 Java 和 cloudflared，不需要安装 Android Studio、JDK、Gradle 或 Git。
Quick Tunnel 完全停止后再次启动，公网地址可能变化；两台手机需要使用同一个新地址。
